# Design reference — visual truth only

The prototypes in this directory are **visual truth, not code to copy.** They
are vanilla HTML/CSS. Reproduce their *appearance* in React + Tailwind using
tokens from `docs/DESIGN-SYSTEM.md`.

Never import, copy, or reference these files at runtime.

If a prototype and `docs/DESIGN-SYSTEM.md` disagree, the documentation wins —
flag the conflict rather than guessing.
